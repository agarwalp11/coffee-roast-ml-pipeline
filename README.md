# Coffee Roast Preference Prediction

A reproducible machine learning pipeline that predicts
preferred coffee roast level using survey responses
from the Great American Coffee Taste Test.

## Machine Learning Problem

- Type: Multiclass classification
- Target: roast_level
- Features: brew, strength, style, cups

## Project Overview

This project is developed for Duke University's
AIPI 510 Module Project 3.

The pipeline will include:
- Cloud data storage and ingestion
- Data preprocessing
- Model training and evaluation
- Experiment tracking
- Model API deployment
- Interactive frontend application
